# **App Name**: Ààbò Digital Shield

## Core Features:

- Login page: Basic auth with the OAUTH option of google.
- Landing Page: Landing page with clear value proposition and call to action.
- Onboarding: Onboarding flow with minimal steps to connect WhatsApp and email also Whatsapp Integration feature to receive messages and alerts from the web app through a WhatsApp bot.
- Main Dashboard: Dashboard to view protection status, recent activity, and quick actions.
- Backup Center: Interface to view and manage backup activities.
- Ààbò Co-Pilot: AI-powered chatbot that serves as a security awareness tool (Would integrate OpenAI API).
- Panic Trigger: Panic trigger page with options to send help, security tips, or shut down services.
- Settings/Preferences: Settings page to manage profile, integrations, and preferences.
- Whatsapp Integration: Whatsapp Integration feature to receive messages and alerts from the web app through a WhatsApp bot
- Profile Page: Other important features like profile page.

## Style Guidelines:

- CTA buttons #005B4A Signals safety.
- Hero section BG #FDF7ED Soft, welcoming intro
- Main dashboard BG #FDF7ED Keeps app clean and minimal
- Text color #1C1C1C Maximum readability
- Panic button #D7263D Urgent but not chaotic
- Tips/highlights #F5C042 Friendly, not warning-focused
- Body and headline font: 'Inter' (sans-serif) for a modern, accessible style with bold headers and soft body text.
- Mobile-first design with cartoonish illustrations of Ààbò bot and market sellers to represent real hustle and friendliness (It is a mobile web app).
- Clean and uncluttered layout, friendly and empowering tone to convey security in an accessible way.
- Integrate security in the design use secure headers, implement input validation and other important ones
